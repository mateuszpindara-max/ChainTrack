# Dashboard token values

The scoped values below keep the established ChainTrack dark surface and orange accent. The background and surface values come from the existing `bg-cosmic` gradient in `src/styles/global.css`; the accent and status values adapt the existing Tailwind colors used in `src/components/ActivityDashboard.tsx`, `src/components/DashboardSidebar.tsx`, and `src/components/ChainDetails.tsx`. The primary foreground changes to a dark color so orange action surfaces retain readable contrast.

| ---------------------- | ------------------------ |
| background             | `#0a0e1a`                |
| foreground             | `#f8fafc`                |
| surface                | `#0f1529`                |
| primary                | `#f97316`                |
| primary foreground     | `#111827`                |
| muted foreground       | `#bfdbfe`                |
| accent                 | `rgb(255 255 255 / 10%)` |
| border                 | `rgb(255 255 255 / 15%)` |
| input                  | `rgb(2 6 23 / 60%)`      |

| success                | `#a7f3d0`                |
| warning                | `#fde68a`                |
